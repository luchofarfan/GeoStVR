# Mi Proyecto de Práctica Git Flow

Este es un proyecto de ejemplo para practicar Git Flow y control de versiones.

## Características
- Control de versiones con Git
- Flujo de trabajo organizado
- Branches para diferentes funcionalidades

## Instalación
```bash
git clone <url-del-repositorio>
cd mi-proyecto
```

## Uso
Este proyecto es solo para fines educativos y práctica de Git.
